# Contributing
Start with a reproducible problem or a small documented improvement.
Run `python -m unittest discover -s tests -v` before proposing a change.
For bugs, include your Python version, command, expected behavior and traceback.
Use synthetic examples; never upload private property records or credentials.
Explain data provenance and license for proposed datasets.
Keep pull requests focused and explain the behavior being changed.
AI-assisted contributions are welcome when reviewed, tested and understood.
Useful next contributions: group-aware splits, categorical features, and a properly licensed real-data example.
